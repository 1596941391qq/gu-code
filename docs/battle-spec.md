# 蛊码 v2 战斗规格（数据格式与引擎接口）

> 规则来源是 docs/design.md（第 1 节羁绊、2.5 战斗、3.5 SOTA、第 8 节策略性）。本文件定「数据长什么样、引擎怎么读」。
> 引擎 src/battle.js、画面 src/battle-view.js、杀招动画 src/combo-fx.js 归战斗一侧；其余专家只交数据，按本文件的格式。
> 2026-10-31 第二版（3×3 阵盘、技能形状与位移、跨道状态触发）。字段只增不改；改了格式先改这里。

## 0. 总原则

- **数值一律按比例**：伤害、治疗、护体、增减益都写成「攻 / 血 / 速的百分比」，再按转数放大。后期攻血变大，技能照样举足轻重。
- **确定性**：战斗里所有随机只走种子随机（`ctx.rng`）。同种子、同阵容、同参数 → 同一场，逐事件一致。
- 战斗里用到的东西只有：攻、血、速、近战/远程、蛊力、主动技、本命技、挂着的食物、蛊性、杀招、道共鸣、阵盘站位、SOTA。

## 0.5 阵盘

- 双方各一块 3 行 × 3 列：`pos = { r: 0..2, c: 0..2 }`，c = 0 前列、1 中列、2 后列；合起来是 6 × 3 的战场。空格合法。
- 没有 `pos` 的旧数据按一排顺序自动摆：第 i 只放在列 `floor(i / 3)`，行按 中、上、下（`layoutOf(team)` 导出，返回每只的 `[r, c]`）。
- **相邻**：上下左右；**身后** = 同一行 c 更大的那只；**身前** = 同一行 c 更小的那只；**同列** = 同一 c。
- 引擎内部仍保留一条「列→行」排好的顺序给现有钩子式本命技用（「最前」= 这个顺序的第一只）。

## 1. 单位

### 1.1 洞府/秘境交给引擎的蛊（输入）

```js
{ uid, sp, rank, atk, hp, hpNow?, spd?, food?, xing?, boss? }
```

| 字段 | 说明 |
|---|---|
| `uid` | 存档里这只蛊的 id，结果里原样带回（`units[*].gid`） |
| `sp` / `rank` | 物种、转数（1–5，仙蛊 6） |
| `atk` / `hp` | 攻、满血（卡面数值，已含食物永久加成） |
| `hpNow` | 当前血（卡面单位）。不给 = 满血。秘境血量延续用，进场血 = clamp(round(hpNow), 1, hp) |
| `spd` | 可选，覆盖物种的速（食物加速之类）。不给按物种 |
| `food` | 挂着的食物 id（只有 kind = 'gear' 的在战斗里起作用） |
| `xing` | 蛊性 id（见第 6 节） |
| `pos` | 阵盘格 `{ r, c }`（见 0.5） |

### 1.2 物种上的战斗字段（内容专家在物种数据里加）

```js
{ id, n, atk, hp, nat, dao,
  spd: 100,            // 速：100 = 标准，一般 60–160。不随转数变（相对快慢不贬值）
  reach: 'melee',      // 'melee' 近战 | 'ranged' 远程
  aim: 'low',          // 远程普攻挑谁（目标写法见 3.3 的 pick），默认 'low'；近战固定打最前
  atkFx: 'pounce',     // 普攻动作：pounce 扑击 | slash 横斩 | bite 撕咬 | spit 吐火 | needle 射刺 | bolt 雷光 | spore 孢雾 | wave 音波
  act: { ... } | null, // 主动技（第 4 节），约四成物种有
}
```

没写的字段引擎有默认值（按流派推一个速和近远程），所以可以分批交。

### 1.3 战斗里的单位（引擎内部，渲染层从 `roster` 读）

```js
roster[buid] = { gid, side, src, sp, name, rank, spd, reach, gpMax, act: { n, fx } | null, combo: { id, n } | null, summon, boss }
```

- `buid` 是这一场里的编号：A 方 `a0 a1 …`，B 方 `b0 b1 …`，召唤物接着往后编。
- `src` = 在传入数组里的下标；召唤物为 `null`。
- 战斗血量 = 卡面血 × **HPK（= 4）**，伤害按攻算。卡面「攻 3 血 4」进场是 3 攻 16 血。结果里的 `hpEnd` 已换回卡面单位。

## 2. 时间轴：速度、出手顺序、轮

- 每只蛊有一条行动条，长度 10000，按速充能：从上一次出手到下一次出手间隔 `10000 / 速`。
- 时间到了就出手；同一时刻按 速高 → A 方 → 站位靠前 排序。
- **轮**：每过 100 个时间单位算一轮（速 100 的蛊每轮出手一次）。每轮开始先结算毒、灼等，再触发「每轮开始」效果。
- 改速（加速/减速）时，剩下的那段按新速度折算；「提前 / 推后」直接把行动条推进或拉回一个百分比。
- 每次出手事件都带 `q`：接下来约 8 次出手的顺序（含轮次分隔 `'#3'` 表示第 3 轮开始），出手顺序条直接画它。
- 开战时每只蛊的行动条起点在 55%–100% 之间（种子随机）：速快的整体出手更勤，但第一下不是每次都被它抢到。
- 速对出手间隔的影响按 `SPD_K`（现为 0.10）折算：速 120 的蛊出手频率是速 100 的 1 + 0.2 × 0.10 倍。模拟口径：同攻血镜像阵容速 +20% 的一方胜率在 55%–65%。
- 第 20 轮起「天劫压阵」：每轮开始全体掉最大血量 (轮数 − 19) × 10%，杜绝互相回血打不完；第 30 轮还没分出胜负算平局。

## 3. 出手、蛊力、站位

### 3.1 一次出手

1. 「出手前」：眩晕的跳过这次（消耗一层）。
2. 蛊力满了且有主动技 → 放主动技（屏幕打出技能名），蛊力清零。
3. 否则普攻：
   - **近战**打**同一行最靠前**的敌蛊，这一行没人就打最近的一行（行距相同先上后下）。同一行身前有友蛊挡着的近战够不着，改为「蓄势」：不出手，蛊力 +60。
   - **远程**按物种的 `aim` 挑目标，可以打后排。
   - 出手前先在阵盘上标出目标格（事件里的 `cells`），画面停一拍再打。
   - 普攻伤害 = 攻 ×（暴击 10% 机会 ×1.5）。命中后触发「普攻命中」。
4. 「出手后」。

### 3.2 蛊力

- 开战 +20；每次出手 +34（被挡住的近战蓄势 +60），每被敌方打中一次 +15。满了（`act.cap`，默认 100）下一次出手放主动技。
- 没有主动技的蛊不攒蛊力，只靠本命技。

### 3.3 目标写法 `tg`

`方.挑法[:数量]`，方 = `foe` 敌方 / `ally` 友方；`self` 单写。

| 挑法 | 意思 |
|---|---|
| `front` | 离我最近（同一行最靠前优先，再看行距；`front:2` = 最近两只）。`ally.front` = 我方最靠前的 |
| `last` | 最靠后（后列优先） |
| `low` | 当前血最少 |
| `lowp` | 血量比例最低 |
| `top` | 攻最高 |
| `fast` | 速最快 |
| `rand` | 随机（`rand:2` 随机两只，不重复） |
| `all` | 全体 |
| `adj` | 上下左右相邻（只用于 ally） |
| `near` | 周围一圈 8 格（只用于 ally） |
| `row` / `col` | 和我同一行 / 同一列的友蛊（只用于 ally） |
| `behind` / `ahead` | 同一行身后 / 身前最近的一只（只用于 ally） |
| `tg` | 本次事件的目标（普攻命中时 = 被打的那只） |
| `src` | 本次事件的来源（受击时 = 打我的那只） |
| `killer` | 击杀我的那只 |
| `same` | 和上一条效果同一批目标 |

嘲讽（`taunt`）的敌蛊会被近战、远程普攻和单体 `foe.*` 技能优先选中（`all` 不受影响）。

### 3.4 技能形状 `shape`

先按 `tg` 挑出锚点，再按形状展开到锚点所在那一方的阵盘：

| shape | 形状 |
|---|---|
| `one`（默认） | 单体 |
| `row` | 整行贯穿：锚点那一行的全部 |
| `col` | 整列：锚点那一列的全部 |
| `cross` | 十字：锚点和它上下左右 |
| `ring` | 周围一圈：锚点和它周围 8 格 |
| `diag` | 斜线：锚点和它的斜对角 |
| `back` | 后排：那一方最靠后一列的全部（可以不写 `tg`，默认对敌方） |

例：`{ op: 'dmg', tg: 'foe.front', shape: 'row', atk: 1.5 }` = 贯穿最近那一行。

## 4. 效果

### 4.1 一条效果

```js
{ op, tg, ...数值, if?, chance?, max?, every?, dur? }
```

**数值键**（可以组合相加）：`atk` 施放者当前攻、`a0` 施放者开战攻、`mx` 施放者最大血、`tatk` 目标攻、`tmx` 目标最大血、`n` 本次事件的数值（这一下伤害、挡下的量）、`flat` 固定值（少用）。
全部再乘 **转数倍率** `1 + up × (转数 − 1)`，`up` 默认 0.12（可在效果上覆盖，0 表示不随转数涨）。

| op | 做什么 | 关键参数 |
|---|---|---|
| `dmg` | 伤害（技能伤害，`kind: 'skill'`） | 数值键；`pierce: 1` 无视护体；`crit: 0.2` 暴击率 |
| `heal` | 治疗，不超过满血 | 数值键 |
| `shield` | 护体（先挡伤害，上限 2 倍满血） | 数值键 |
| `buff` | 增益 / 减益（负数）。这里 `atk` `hp` `spd` 表示**目标自己**开战值的百分比；加 `by: 'self'` 改按施放者 | `atk` `hp` `spd`；`dur` 持续轮数（不写 = 本场一直有效） |
| `st` | 挂状态（4.2） | `k`、`n` 层数/轮数、数值键（毒灼的每轮伤害） |
| `summon` | 召唤 | `sp` 召唤物 id、`atk` `mx`（施放者的百分比）、`at: 'behind' \| 'front' \| 'back' \| 'here'`、`count` |
| `gp` | 蛊力增减 | `v`（可负） |
| `adv` / `delay` | 行动条提前 / 推后（第一版的 `pull` / `push` 仍认，意思相同） | `v`：0.3 = 30% |
| `knock` | 击退：往后挪 `v` 格（默认 1）；身后有蛊挡着就撞上，两只都受伤；已在后列就撞墙受伤 | `bump`：撞击伤害 = 施放者攻 × bump（默认 0.4） |
| `draw` | 拉近：往前挪 `v` 格；身前有蛊挡着就撞上，两只都受伤 | `bump` |
| `swap` | 换位：`with: 'self'` 和施放者换（友方）；`with: 'front' \| 'back'` 挪到同一行最前 / 最后一格，和那里的蛊对调 | |
| `eat` | 吞：目标血量不过 `v`（默认 0.3）或是召唤物，直接吞掉，施放者得到它 `gain`（默认 0.3）的攻血 | `v` `gain` |
| `cleanse` | 去掉目标身上的减益状态 | |
| `endure` | 免死：留 `v` 比例的血（只在 `lethal` 时机里用） | `v` |
| `mul` | 改这一下的伤害倍数（只在 `deal` / `take` 时机里用） | `v`：1.3 = ×1.3 |

**条件** `if`（字符串，多个用 `&`）：`front` 我这一行身前没有友蛊、`back` 身前有友蛊、`last` 身后没有友蛊、`col=0` 我站前列（1 中、2 后）、`k=psn` 这次挂的状态是毒、`hp<50` 我血量低于 50%、`tg.hp<50` / `tg.full` 目标满血 / `tg.psn` 目标中毒 / `tg.burn` / `tg.stun`、`round>=3`、`round%2`（单数轮）、`first`（本场第一次）、`dead.adj` / `dead.ahead`（倒下的是我相邻 / 身前那只）、`melee` / `ranged`（这一下是近战/远程普攻）、`kind=hit`（这一下是普攻）。
**其它**：`chance` 概率；`max` 每场最多几次；`every: 3` 每 3 轮一次。

### 4.2 状态 `st.k`

| k | 名 | 效果 |
|---|---|---|
| `psn` | 毒 | 每轮开始掉血（叠加，上限目标最大血 25%），不被护体挡，不会自己消失 |
| `burn` | 灼 | 每轮开始掉血，持续 `n` 轮（默认 2），再挂刷新轮数、伤害取大 |
| `stun` | 眩 | 跳过接下来 `n` 次出手 |
| `web` | 网 | 接下来 `n` 次普攻落空 |
| `guard` | 护 | 接下来 `n` 次受到的伤害减半 |
| `taunt` | 嘲 | `n` 轮内敌方优先打它 |
| `mark` | 印 | `n` 轮内受到的伤害 +25% |
| `seal` | 封 | `n` 轮内蛊力不涨 |
| `chill` | 寒 | 每层速 −15%，叠到 3 层冻住（眩 1 次）后清空；每轮退一层 |

**状态谁都能读**：任何道的蛊都能用 `if: 'tg.psn'`（目标中毒）、`tg.burn`、`tg.chill`、`tg.stun`、`tg.mark`、`tg.guard`、`tg.summon` 判断，也能用 `inflict` / `allyInflict` 时机接别人挂上的状态（5.1）。跨道配合就靠这些。

## 5. 技能

### 5.1 触发时机 `when`

| when | 时机 | 事件载荷 |
|---|---|---|
| `prep` | 布阵（开战前，先于一切） | |
| `start` | 开战 | |
| `round` | 每轮开始 | `round` |
| `pre` | 自己出手前 | |
| `attack` | 自己普攻命中后 | `tg` `n` |
| `cast` | 自己放完主动技 | |
| `hit` | 受到敌方伤害后 | `src` `kind` `n` |
| `lethal` | 受到致命伤、倒下之前（配 `endure`） | `src` |
| `death` | 倒下（亡语） | `killer` `idx` |
| `kill` | 击杀 | `victim` |
| `allyDeath` / `foeDeath` | 有友蛊 / 敌蛊倒下 | `dead` |
| `summon` | 友方有蛊被召唤 | `u` |
| `front` | 自己换到最前 | |
| `foeFront` | 敌方换上新的最前 | `u` |
| `low` | 自己血量第一次掉到一半以下 | |
| `inflict` | 我给敌蛊挂上了状态（毒、灼、寒、眩、网、印、封） | `k` `tg` |
| `allyInflict` | 友蛊给敌蛊挂上了状态 | `k` `tg` `by` |
| `deal` / `take` | 修正器：自己造成 / 受到一下伤害时（配 `mul`） | `tg`/`src` `kind` `n` |

### 5.2 主动技 `act`（物种上）

```js
act: { n: '焚天吐息', cap: 100, fx: 'fire', d: '一句话说清', eff: [
  { op: 'dmg', tg: 'foe.front:3', atk: 1.2 },
  { op: 'st', tg: 'same', k: 'burn', n: 2, atk: 0.3 },
] }
```

- `cap` 蛊力上限：便宜的技能 70–80，强的 120–150。`fx` = 画面动作：`fire` 吐火、`needle` 射刺、`pounce` 扑击、`summon` 召唤、`slash` 斩、`bolt` 雷、`frost` 冰、`spore` 毒雾、`shield` 护、`heal` 回春、`roar` 吼、`drain` 吸。
- 主动技也可以带 `aw: [[三转追加的效果…], [五转追加的效果…]]`。

### 5.3 本命技（被动，含三转、五转觉醒）

两种写法都认：

1. **声明式**（新写的用这个）：
   ```js
   natX: { n, ch, trig, d, aw: [d三转, d五转], eff: [{ when, op, … }], awEff: [[三转追加…], [五转追加…]] }
   ```
2. **钩子式**（现有 64 种照旧能用，签名不变）：`hooks: { onStart, onTurn, onHit, onKill, onDeath, onSummon, onAttack, onPrep, onFront, onFoeFront, onMourn, onFoeDie, atkMod, dealMod, takeMod, auraTake, saveDeath }`，`ctx` 的接口与 bestiary.js 文件头一致。旧词翻译：**炉口 = 最前**，**对撞 = 普攻**（`kind: 'hit'`），**回合开始 = 每轮开始**，第 N 回合 = 第 N 轮。

本命倍率照旧（bestiary.js 的 `natMulOf`），觉醒看转数：三转起 `aw ≥ 1`，五转起 `aw ≥ 2`。

## 6. 食物挂件与蛊性

- **食物挂件**（foods.js 里 `kind: 'gear'`）：在食物上加 `eff: [{ when, op, … }]`。现有的 `gear: 'spawn' | 'ward' | 'first'` 引擎照旧认（ward 按百分比：`pct` 每次受伤减 pct%）。
- **蛊性**（秘境维护的 `XING` 表，顺序只往后加）：`XING[id] = { n, d, eff: [{ when, op, … }] }`。例：
  ```js
  jianren: { n: '坚韧', d: '每场第一次受到致命伤时留 1 血', eff: [{ when: 'lethal', op: 'endure', v: 0, max: 1 }] },
  shisha:  { n: '嗜杀', d: '每击杀一只，攻 +20%', eff: [{ when: 'kill', op: 'buff', tg: 'self', atk: 0.2 }] },
  ruiqi:   { n: '锐气', d: '每场第一次出手伤害 ×1.5', eff: [{ when: 'deal', op: 'mul', v: 1.5, if: 'first' }] },
  zhanshou:{ n: '斩首', d: '打满血的敌蛊，伤害 ×1.3', eff: [{ when: 'deal', op: 'mul', v: 1.3, if: 'tg.full' }] },
  tongpao: { n: '同袍', d: '相邻友蛊倒下时回 25% 血', eff: [{ when: 'allyDeath', op: 'heal', tg: 'self', mx: 0.25, up: 0, if: 'dead.adj' }] },
  zhenyue: { n: '镇岳', d: '开战站最前，得 25% 护体', eff: [{ when: 'start', op: 'shield', tg: 'self', mx: 0.25, up: 0, if: 'front' }] },
  yuxue:   { n: '浴血', d: '每被普攻打中一次还活着，攻 +10%', eff: [{ when: 'hit', op: 'buff', tg: 'self', atk: 0.1, if: 'kind=hit' }] },
  zhefu:   { n: '蛰伏', d: '身前友蛊倒下时攻血 +15%', eff: [{ when: 'allyDeath', op: 'buff', tg: 'self', atk: 0.15, hp: 0.15, if: 'dead.ahead' }] },
  ```
  `endure` 的 `v: 0` 表示留 1 血。触发时引擎发 `trig { uid, xg }`，画面显示 `XING[xg].n`。

## 7. 羁绊（道共鸣、杀招、进阶杀招、道痕相冲）

### 7.1 道共鸣

```js
DAOS[i] = { id, n, d, r2, r4, r6 }   // r2/r4/r6 = 同道凑到 2/4/6 只时的那一档（取最高一档，不叠加）
r2 = { d: '一句话', atk: 10, hp: 0, sh: 0, spd: 0, gp: 0, eff?: [{ when, op, … }] }
```

道共鸣只给轻量加成：引擎把表里的数值整体乘 `RES_K`（现为 0.5）。`atk` `hp` `spd`：开战时这一道的蛊各加百分之几；`sh`：开战得最大血量百分之几的护体；`gp`：开战蛊力；`eff`：额外效果，只作用于这一道的蛊（效果的施放者 = 这只蛊自己）。召唤物不算只数。

### 7.2 道痕相冲

```js
// 写在道上：两道同时有共鸣（≥2 只）时，两边共鸣的数值都 ×倍率（取更狠的那个）
DAOS[i].clash = { bing: 0.5 }   // 例：炎道 { id: 'yan', …, clash: { bing: 0.5 } }
```

### 7.3 杀招

```js
COMBOS[i] = { id, n, need: ['boar', 'fire', 'twin'], core: 'boar', d: '一句话',
              when: 'start', eff: [{ op: 'dmg', tg: 'foe.front:3', atk: 0.8 }],
              from?: 'baseId',     // 进阶杀招：写上原杀招 id，need 写全（原配方 + 新加的一两只），成形后取代原杀招
              fx?: { … } }         // 可选：动画提示，不写由 combo-fx.js 按 id 配
```

- **成形**：`need` 里的物种同时在空窍。**核心蛊** `core`（不写 = `need[0]`），挂在站得最靠前的那只核心蛊身上，由它释放。
- **品级** = 核心蛊转数；**所属的道** = 核心蛊的道。
- **威力倍率** = `(1 + 0.15 × (核心转数 − 1)) × (1 + 0.2 × 共鸣档)`，共鸣档 = 这一道当前生效的档 2/4/6 → 1/2/3（相冲打折后按比例算）。杀招所有数值键都乘这个倍率（不再乘 4.1 的转数倍率）。
- **进阶**：进阶杀招成形时，原杀招不再生效。一个队伍里同一只蛊最多挂一个杀招。
- **触发**：按 `when` 触发，一场里**第一次**触发时打出全屏书法招式名和独立动画（`combo` 事件），之后再触发只闪一下印（`quiet: 1`）。`max` 照常可用。
- 也可以写 `hooks`（签名 `hooks.onX(ctx, u, c, go)`，与 bestiary.js 现有杀招一致）。但只要杀招写了 `eff`（combos2 的杀招全都写了），bestiary.js `NEW_COMBOS` 里同 id 的旧钩子就不再派发，免得同一个杀招的效果算两遍。旧本命技钩子里的 `u.combo === 'xxx'` 特判，所在的本命已经整体换成声明式，不会再跑到。

### 7.4 `synergyOf(team)`（纯函数，battle.js 导出）

洞府在空窍上方画「正在生效的共鸣和杀招」用：

```js
synergyOf(team) → {
  daos:   [{ dao, n, name, cnt, tier, next, eff, d, clash, clashWith }],  // cnt 只数，tier 0/2/4/6，next 下一档还差几只，clash 打折倍率（1 = 不打折）
  combos: [{ id, n, core, idx, rank, dao, mul, from, d }],               // idx 挂在空窍第几只身上，mul 威力倍率
  clashes:[{ a, b, k }],
  line:   '力道·4  血道·2（与炎道相冲 ×0.5）  ·  杀招：烈火三豕冲（三转 ×1.5）'
}
```

## 8. 引擎接口

```js
import { battle, synergyOf, layoutOf, battleProfile, predictOrder, encodeReplay, decodeReplay } from './battle.js';
const res = battle(teamA, teamB, seed, opts);
```

`opts`（都可省）：`{ sota: [boolA, boolB] 或 { A, B }, maxRounds: 30, lite: false, noSyn: [a, b], comboOnly: [idsA, idsB] }`（noSyn、comboOnly 只给模拟做对照：noSyn 关掉某一方的全部羁绊；comboOnly 某一方给杀招 id 数组时只保留这些杀招，给 `[]` 就是杀招不成形、道共鸣照旧，用来测杀招增益）
- `battleProfile(sp)` → `{ spd, reach, aim, atkFx, act }`：蛊卡、蛊典显示速、近远程、主动技用（物种没写的字段按引擎默认值补）。
- `sota`：design.md 3.5 的彩蛋。为 true 的那一方，所有伤害 ×1.01（四舍五入）。
- `lite: true` 不写每步快照（模拟用，快很多）。

返回：

```js
{ winner: 'A' | 'B' | 'draw', rounds, seed, sota: [a, b],
  log: [事件…],                      // 第 9 节，够画面完整重放
  roster: { buid: {…} },             // 1.3
  units: { buid: { gid, side, src, sp, name, summon, dmg, taken, healed, kills, acts, casts, hpEnd, mx, dead } },
  mvp: buid,                         // 本场最佳（胜方里 伤害 + 0.5 × 承受 + 0.5 × 治疗护体 最高的）
  hpA: [卡面剩血…], hpB: [...],     // 按传入顺序；0 = 倒下；不超过卡面满血；召唤物不算
  statA: [{ kills, hits, taken, killT1, oneShot, adjFell, frontFell, front, acts, casts, dmg, hp, mx }…], statB: [...]
}
```

- `hpEnd` / `hpA`：卡面单位，`ceil(战斗剩血 / HPK)`，活着至少 1，不超过卡面满血（场上临时加的血不带出战斗）。
- **倒下 = 永久死亡**以 `dead: true` / `hpA[i] = 0` 为准（复活、免死类效果已算完）。
- `statA` 口径：`hits` 被敌方普攻（近战或远程）打中次数；`taken` 实际掉血（护体挡掉的不算，卡面单位，向上取整）；`killT1` 第 1 轮内有击杀；`oneShot` 一下打死满血敌蛊；`adjFell` / `frontFell` 相邻 / 身前友蛊倒下过；`front` 开战站最前。
- **复盘**：`encodeReplay({ A: 坐标码, B: 坐标码, seed, kind, sota })` → `'<A>.<B>.<seed>.<kind>.<s>'`，`s` = SOTA 两位（0–3，A 为 1、B 为 2）；`decodeReplay(text)` 认新旧两种链接（旧链接没有 `s` 段，按 0）。
- **坐标码**：v6 由洞府一侧定（core.js）：v5 后面每只蛊加阵盘格 4 位（0–8，15 = 没摆）和速 8 位（0 = 按物种）；v1–v5 照旧能解。

## 9. 事件（log）

每个事件 `{ t, …, s? }`；`s` = 这一步之后的快照 `[[buid, 攻, 血, 护体, 蛊力, 速, 行, 列, 状态] …]`（A、B 两方各一组），`lite` 时省略。状态 = `0` 或 `{ psn: 每轮伤害, burn: [每轮伤害, 剩几轮], chill: 层, stun, web, grd: 护的次数, mark, seal, taunt, para, by: { 状态: 谁挂的 buid } }`，画面的状态图标和层数都读它。

| t | 字段 | 说明 |
|---|---|---|
| `begin` | `A` `B`（buid 列表）`q` | 开战，`q` 是最初的出手顺序 |
| `syn` | `side` `daos` `combos` | 开战时这一方生效的共鸣和杀招 |
| `round` | `n` | 第 n 轮开始 |
| `act` | `uid` `q` | 轮到它出手；`q` 接下来约 8 次出手（含 `'#n'` 轮次分隔） |
| `skip` | `uid` `k` | 眩晕/后排蓄势跳过（`k: 'stun' \| 'charge'`） |
| `atk` | `uid` `tg` `fx` `reach` `crit` `cells` | 普攻（随后跟 `dmg`）；`cells = [[方, 行, 列]]` 是出手预告要标的格子 |
| `cast` | `uid` `n` `fx` `tg: [buid]` `cells` `shape` `line` | 放主动技；`line` = 这一下的说明换成实际数字（「咬最近的敌蛊，28 伤害，中毒」），亮牌用 |
| `combo` | `uid` `id` `n` `quiet` `tg` | 杀招 |
| `dmg` | `uid` `src` `n` `blk` `k` `crit` | `k`：`hit` 普攻 / `skill` / `psn` / `burn` / `bump` 撞击 / `thorn` / `mirror` / `self` / `doom` |
| `heal` | `uid` `n` | |
| `buff` | `uid` `a` `h` `sh` `spd` | 增减益、护体 |
| `status` | `uid` `k` `n` `by` | 挂上状态（`by` = 谁挂的） |
| `link` | `uid` `to` `k` | 联动：效果因为目标身上的状态才触发（`if: 'tg.psn'` 等），或接友蛊挂上的状态（`allyInflict`）；画面在两只之间画一道线 |
| `trig` | `uid` `id` / `xg` / `food` / `dao` | 被动触发了（本命、蛊性、食物、共鸣），画面小字 |
| `summon` | `uid` `by` | |
| `move` | `uid` `r` `c` `k` `into?` | 站位变了：`k` = `knock` 击退 / `draw` 拉近 / `swap` 换位 / `bump` 撞上（没挪动，`into` = 撞上的那只）/ `wall` 撞墙 / `hold` 镇住没动 |
| `order` | `q` | 开战结算完后的出手顺序 |
| `faint` | `uid` `eaten?` `by?` | 倒下（被吞时 `by` = 吞它的那只） |
| `end` | `w` | |

## 10. 本命技与主动技的来源（第三版）

- 120 种蛊的被动技能全部是声明式（`bestiary2.js` 的 `NATS`，集成时换进 `NEW_TRAITS`），数值按每条效果的 `up` 随转数涨（4.1 节公式），引擎不再乘 `natMulOf`，旧的钩子折算表 `NAT_K` 作废（导出一个空表兼容旧代码）。只有春秋蝉 `rewind` 保留原钩子。
- 主动技只认物种上的 `act`（`PATCH64` / `SPECIES2` 带上），没写就是没有主动技，引擎不再补占位主动技。
- 免死（`lethal` 时机的 `endure`）成功后，同一块里 `lethal` 时机的其它效果（加攻、召唤、退到末位、挂护……）接着跑一遍。

## 11. 秘境挂件 `g.fx` 与开关 `flag`（第三版）

单位输入可以多一个 `fx: [{ id, n, kind: 'sky' | 'boss' | 'bless', eff: [...] }]`，`eff` 写法同蛊性；触发时发 `trig { uid, fx: id, n }`，画面显示 `n`。召唤物不跟着挂。

通用效果 `{ when, op: 'flag', tg, k, v }`：把目标的开关 `fl[k]` 设成 `v`（不写 `v` 就是 1）。引擎读这几个：

| `k` | 作用 |
|---|---|
| `gpMul` | 攒蛊力乘这个数（灵潮） |
| `psnMul` | 这只蛊给别人挂毒时层数乘这个数 |
| `bumpMul` | 这只蛊击退造成的撞伤乘这个数 |
| `noSummon` | 这只蛊放不出召唤 |
| `noRevive` | 这只蛊的免死不生效，亡语召唤也不出，春秋蝉倒转光阴也不触发 |
| `immune` | 状态名数组，例如 `['psn']`，挂不上这些状态（寒 / 冻住都算 `chill`） |

另有 `{ when: 'prep', op: 'copyNat', tg: 'foe.front' }`：照抄目标的被动技能（含已觉醒的部分，按施放者转数算），本场有效，一场只抄一次。

`{ when: 'start', op: 'echo', tg: 'self', k: 'death' }`：把目标身上 `when === k`（默认亡语）的效果原样跑一遍，目标本身不倒（引魂香）。发 `trig { uid, …, echo: k }`。

挂件或单位上的 `noMove: true`（镇石）：跳过击退、拉近、换位，不移动也不撞，发 `move { k: 'hold' }`。`mul` 的 `v: 0` 表示这一下全免（伤害最少记 1）。

受击连锁的保险：受击反应里打出去的伤害（照回、反刺），不再触发对方的受击效果；旧钩子最多再嵌两层。镜对镜不会无限互弹。

### 11.1 数值放大十倍（design 2.8）

攻血由 `core.statFor` 乘 `STAT_SCALE`，数据里只有百分比。引擎里写死的固定数同步乘 10：毒的叠加上限保底 6 → 60、护体上限保底 99 → 990、灼没写数值时每轮 1 → 10、攻血上限 99999 / 999999 → 999999 / 9999999。所有「最少 1 点」的保底不变。

### 11.2 状态与杀招的总体强度 `TUNE`

`TUNE = { burn, psn, chill, combo }`（battle.js 导出，可改）：灼每轮伤害、毒每轮伤害、寒每层减速（默认 15%）、杀招效果的倍率。模拟调参用 `GU_TUNE='{"burn":0.6}' node tools/sim.mjs`。

## 12. 画面接口（battle-view.js / combo-fx.js）

- `playBattle(el, result, opts) → Promise<{ closed, skipped }>`：结算页点「继续」才 resolve。`opts = { title, mode: 'trip' | 'spar', names: [我方, 对方], mySide: 0 | 1, speed: 1 | 2, reduceMotion, sota }`。
  - `mode: 'trip'`（秘境）：赢了，倒下的蛊在画面上从倒地起身，结算写「救回 N 只」（剩多少血由秘境定，这里不写）；没赢，结算页「全队告别」逐只列出永久离开的蛊，停住等点击。
  - `mode: 'spar'`（斗幽灵、战帖、复盘）：结算不提死亡，只写「切磋：不死蛊」。没写 `mode` 时按旧参数猜（`perm` 或 `kind: 'trip'` 当秘境）。
  - 跳过：直接到结算页。`reduceMotion` 关掉震屏、把闪白压到很淡、镜头推拉减半（对应设置「减弱震屏和闪光」）。
- `skillText(sp, rank, opts) → [{ kind, n, text, locked?, at?, lines? }]`（battle.js）：蛊详情和合成预览用。`kind` = `passive` 被动技、`active` 主动技、`aw3` / `aw5` 三转 / 五转觉醒（`lines` 分被动、主动两条）；没到的觉醒 `locked: true`，数字按觉醒那一转算。`text` = 数据里的说明（随转数变的数已换成这一转的值）+ 括号里这一转的实际数字，例如「（这一转约 41 伤害，撞上约 12）」。攻血按卡面数（statFor）算。`opts.est === false` 不补括号。
- 画面怎么读事件（hacking 两条反馈后定）：
  - 主动技三步：蓄势（施放者放大描边，目标格按形状亮起，头顶上方的空白里冒出实色技能牌：敌方朱红、我方青绿，写「敌 · 蜈蚣蛊」「百足噬」和 `cast.line`）→ 亮牌（牌子描金）→ 结算（伤害、状态逐个跳出，牌子留到下一次出手）。1× 蓄势约 0.4 秒，2× 减半，跳过才省掉。
  - 出手顺序条：蛊力满的蛊下一次出手会放主动技，头像加「技」角标和金色光圈，悬停看技能名和效果。
  - 战斗记录：阵盘下方 4～6 行可滚动，一次出手一行，「[敌] 蜈蚣蛊 放「百足噬」→ 分身蛊 -28，中毒（每轮 8）」，敌方朱红、我方青绿；杀招、每轮结算、联动、召唤、倒下都写进去。
  - 状态：挂上那一下有动画（灼火苗、毒气泡、寒结霜、冻住冰块、护光罩、印靶、眩金星、网、封印），挂着时头顶有图标带层数（灼 = 剩几轮，毒 = 每轮伤害，其余 = 层数 / 次数），身上带持续效果（余火、绿晕、霜色、光罩、靶印、晕圈）；每轮结算的跳字灼橙红带火苗、毒绿字带气泡；`link` 画一道弧线。点按或悬停任何一只蛊：主动技、被动技（`skillText`，按它这场的攻血算）和身上每个状态（谁挂的、剩多少、每轮效果）。
  - `reduceMotion`：挂状态的动画改成淡入淡出，图标和层数照常。
- `playCombo(stage, o) → Promise`：杀招动画（每个杀招一份配方，进阶杀招名字条带金边）；`comboSheet(el)` 画全部杀招的关键帧总览；`drawComboFrame(ctx, id, ms, w, h)` 画单帧。没写配方的新杀招按 id 稳定地拼一份，进阶杀招（`xxx2`）在原版上加金光收尾。
